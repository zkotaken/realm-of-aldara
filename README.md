# Realm of Aldara Classic builds

Files for the Realm of Aldara Launcher. Each Windows build of Realm of Aldara Classic is listed in `manifests/<version>.json`: every game file with its SHA-256 and the gzip parts it is made of. Parts live in `parts/<sha256 of the part>.gz`, so pieces that do not change are shared between versions and only changed files are downloaded.

The game's source is on the `unity-classic` branch.
